# Keep It Simple

Keep It Simple is a Fabric modpack focused on minor content additions that promote adventuring and questing, paired with the performance optimizations and quality-of-life features that modded players expect. It is currently in alpha, with more content on the way.

---

## What's Included

### Optimizations
Client and server performance is a first-class priority. The pack ships a full suite of rendering, memory, networking, and game-logic optimizations so the game runs smoothly whether you are playing solo or on a server.

- Extended render distances without the FPS cost
- Rewritten chunk rendering for dramatically higher framerates
- Reduced memory usage across block states and world data
- Optimized networking, AI, ticking, and world generation
- Smart entity and block culling to skip rendering what you cannot see
- Background throttling so the game does not hog resources when minimized

### Visuals
The world looks the way it should. Shader support, dynamic lighting, enhanced entity textures and models, realistic sound propagation, and quality particle behavior are all included and ready to use out of the box.

### Utility and Quality of Life
The small things matter. Block and entity tooltips, a minimap with waypoint support, enchantment descriptions, food saturation display, and a handful of other additions surface information that vanilla leaves hidden.

## Installation

1. Download the `.mrpack` for your Minecraft version from the [Releases](https://github.com/MisterVitoPro/keep-it-simple-modpack/releases) page.
2. Import it into your launcher:
   - **Prism Launcher / MultiMC:** File > Import Instance
   - **ATLauncher:** Instances > Import
   - **CurseForge App:** Create Custom Profile > Import

No additional setup required.
